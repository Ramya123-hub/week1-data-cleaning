# Week 1: Data Cleaning and Exploration Using Pandas

## Project Overview
This project focuses on cleaning and exploring an applicant dataset using Python and the Pandas library. The goal is to improve data quality by identifying and handling missing values, removing duplicate records, standardizing text, and correcting data types.

## Objectives
- Explore the dataset using Pandas.
- Identify missing values and duplicate records.
- Handle missing values appropriately.
- Remove exact duplicates and repeated valid email addresses.
- Standardize applicant names, email addresses, application domains, and statuses.
- Convert application dates into a consistent datetime format.
- Clean phone numbers.
- Export the cleaned dataset as a CSV file.

## Tools and Technologies
- Python
- Pandas
- Google Colab
- GitHub

## Dataset
The practice dataset contains applicant information, including:
- Applicant Name
- Email
- Phone
- Domain Applied
- University
- Application Date
- Status

## Data Cleaning Process
1. Loaded and explored the dataset.
2. Examined missing values and duplicate records.
3. Handled missing values using appropriate placeholders and removed records without applicant names.
4. Removed exact duplicates and checked for repeated valid email addresses.
5. Standardized text values and domain categories.
6. Converted application dates into datetime format.
7. Removed spaces and hyphens from phone numbers.
8. Verified the cleaned data and exported the final CSV.

## Files Included
- `week1_data_cleaning_ramya.ipynb` — Jupyter notebook containing the analysis and cleaning steps.
- `applicants_cleaned.csv` — cleaned applicant dataset.

## How to Run
1. Download or clone this repository.
2. Open the notebook using Google Colab or Jupyter Notebook.
3. Ensure the original `applicants.csv` dataset is available if you want to rerun the entire notebook from the beginning.
4. Run the notebook cells in order to reproduce the cleaning process.

## Outcome
The project demonstrates basic data exploration, missing-value handling, duplicate removal, text standardization, date conversion, and CSV export using Pandas.
